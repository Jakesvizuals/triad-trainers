# Triad Trainers PokéNav

A heavily Pokémon-inspired, fan-made Pokémon GO community dashboard for the Piedmont Triad.

## What is included

- Animated PokéNav boot screen
- Trainer dashboard
- Adventure Schedule
- Raid Lobby
- Professor's Lab
- Shiny Sightings
- Hundo Radar countdown
- Trade Corner
- Route Finder
- Wayfarer Workshop
- GO Lounge
- Responsive iPad and phone layout

## Run on iPad with Replit

1. Download and unzip the project, or import the ZIP directly into Replit.
2. Open `index.html`.
3. Use Replit Preview to view it.
4. Publish it when ready.

No Python or Node server is required. This version runs with HTML, CSS, and JavaScript.

## Customize

Replace placeholder buttons and event content in `index.html` with:
- Your Campfire group link
- Your community rules link
- Real event dates and locations
- Your preferred trainer name and level
